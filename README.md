# Antivirus-software

Програма для виявлення шкідливого програмного забезпечення на Вашому персональному комп'ютері. 

Написаний нашвидкуруч. Не всі деталі пропрацьовані.  

Базу даних із сигнатурами шкідливого програмного забезпечення не надано у цьому репозиторії через обмеження щодо її розповсюдження.
